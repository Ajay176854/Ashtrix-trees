# ⚡ Ashtrix Tees — Server Optimization Guide (SEO & Perf)

### 1. Enable Gzip Compression (.htaccess / Apache)
```apacheconf
<IfModule mod_deflate.c>
  AddOutputFilterByType DEFLATE text/html text/plain text/xml text/css text/javascript application/javascript application/x-javascript application/json
</IfModule>
```

### 2. Browser Caching (Static Assets)
```apacheconf
<IfModule mod_expires.c>
  ExpiresActive On
  ExpiresByType image/jpg "access plus 1 year"
  ExpiresByType image/jpeg "access plus 1 year"
  ExpiresByType image/gif "access plus 1 year"
  ExpiresByType image/png "access plus 1 year"
  ExpiresByType image/webp "access plus 1 year"
  ExpiresByType text/css "access plus 1 month"
  ExpiresByType application/pdf "access plus 1 month"
  ExpiresByType text/x-javascript "access plus 1 month"
  ExpiresByType application/x-shockwave-flash "access plus 1 month"
  ExpiresByType image/x-icon "access plus 1 year"
  ExpiresDefault "access plus 2 days"
</IfModule>
```

### 3. Nginx Strategy (Compression + WebP)
```nginx
server {
    gzip on;
    gzip_types text/plain text/css application/json application/javascript text/xml application/xml application/xml+rss text/javascript;

    location ~* \.(?:ico|css|js|gif|jpe?g|png|webp)$ {
        expires 1y;
        add_header Cache-Control "public";
    }
}
```

### 4. Image Strategy (WebP Optimization)
*   **Recommendation:** When uploading products to the backend, use a library like `Pillow` (Python) to auto-convert to WebP.
*   **Format:** `image.save(fp, format="WEBP", quality=80)`
